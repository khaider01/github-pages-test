How to cite this site

Use the repository URL and the date you accessed it, for example:

Khaider, K. (2026). 6PPD-Q Data Hub.
https://khaider01.github.io/github-pages-test/
Accessed: 21 November 2026.

Update the author, year and access date before publishing or citing. The written content is a working draft; cite the underlying papers for any scientific claim.

Contributing

  • Found an error? Open an issue in the repository with the page and the sentence.
  • Have data? Records need site, type, region, date, concentration and a source reference.
  • Have a figure? Add it to assets/img/ and reference it from the relevant page.
  • No build step: edit the file, commit, push — GitHub Pages serves it as written.
