Making tire-derived 6PPD-quinone data usable

A chemical that wears off our tires is washing into streams and killing coho salmon before they can spawn. The 6PPD-Q Data Hub pulls the measurements, methods and findings about it into one place — so they can be read, compared and questioned instead of sitting in scattered PDFs.

Explore the data Read the story

What this project is for

Three goals, in order of importance: make the science legible, make the data reusable, and make the gaps obvious.

6PPD-quinone (6PPD-Q) was only identified as a widespread urban runoff contaminant in 2020, yet it is now one of the most-studied tire-related chemicals in the environment. Research has grown faster than the ability to compare it: different matrices, different detection limits, different ways of reporting a result.

This hub is a single, citable place to see what has been measured, how, and where — starting with the Puget Sound work on coho salmon and widening from there.

It is deliberately small and static: plain HTML, plain JavaScript, no build step. Everything you see lives in a public repository, so anyone can check a number or fix a typo.

Fields captured for each measurement
Field What it holds
siteSampling location as reported by the study
typeRoad runoff, receiving water, stormwater pond, effluent, laboratory leachate
regionWatershed or region used for grouping
dateYear and month of collection
value6PPD-quinone concentration in ng/L

Data status: the explorer currently runs on a small illustrative sample so the layout and analyses can be tested. Replace DATASET in assets/js/explore.js with a real export and every chart, table and statistic updates automatically.

Queryable database (next): a hosted, open-access database with its own query interface is the natural next step after this static version. The explorer is designed to be swapped onto that backend without changing the pages.
