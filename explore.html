Find your own answer in the data

Choose a slice of the database, then run a premade analysis. Every number below is computed in your browser from the current selection — nothing is hard-coded into the charts.

Sample data. This view is wired to an illustrative 26-row dataset so the layout and analyses can be exercised. Values are not literature results and must not be cited. To go live, replace the DATASET block in assets/js/explore.js with your export.

Scroll the chart sideways to see the full axis.

How to read the reference line. The dashed marker sits at 95 ng/L, the approximate acute toxicity threshold for coho salmon reported in the literature. Bars that cross it represent concentrations in the range that has killed coho in stormwater exposures.

What the filters do. Region and site type are applied before every analysis, so changing either one recomputes the chart, the table and the summary tiles from scratch. Use the CSV download to take the exact selection into R, Python or a spreadsheet.

The premade functions

The explorer runs on a small, readable helper library (gp) defined at the top of assets/js/explore.js. These are the building blocks behind every chart and table — re-use them when you add a new analysis.

gp.filter(rows, { region, type })

Returns only the rows matching the current selection. Called before every analysis.

gp.groupBy(rows, keyFn)

Buckets rows by any field — site type, region, month — and returns an object of arrays.

gp.summary(rows, keyFn)

One call gives n, median, mean, maximum and the share above the reference threshold for each group.

gp.median(values) · gp.mean(values)

Distribution helpers that ignore nothing: filter out non-detects explicitly if your data needs it.

gp.csv(rows)

Serializes the selection to CSV with quoted fields, ready for a spreadsheet or a notebook.

barChart() · lineChart()

Dependency-free SVG renderers. They take plain arrays and inherit the site's colour scheme.

Adding a new analysis

Each analysis is one entry in the VIEWS object. Add a key, give it a label and a chart(rows, target) method that draws the chart and returns the table columns:

VIEWS.byRegion = {
  tab: "By region",
  chart(rows, target) {
    const stats = gp.summary(rows, (r) => r.region);
    barChart(target, stats.map((s) => ({ label: s.name, value: s.median })));
    return {
      caption: "Median concentration by region.",
      head: [{ label: "Region" }, { label: "Median (ng/L)", num: true }],
      body: stats.map((s) => [s.name, gp.fmt(s.median)])
    };
  }
};

Then add a button to the tab list in explore.html: <button class="tab" type="button" role="tab" aria-selected="false" data-view="byRegion">By region</button>. Nothing else needs to change — the wiring picks up every element with data-view.
